# NVDA Time Machine

Build a fully functional historical investment calculator focused exclusively on NVIDIA (NVDA). Users should enter an investment amount in USD and explore how that investment would have performed over time using Daily, Weekly, Monthly, and Yearly timeframes. The interactive historical chart should include a draggable date cursor that shows exactly how much the investment would have been worth at the selected point in history, including profit/loss, ROI,  and total return. It should support both one-time investments and recurring monthly investments, answering questions such as “What if I invested $1,000 in NVIDIA 10 years ago?” and “What if I invested $500 every month into NVIDIA?”. All calculations must use NVIDIA’s actual historical market data and update dynamically as the user changes the investment amount, timeframe, or historical date. The calculator must function as a genuine NVIDIA Market Time Machine, not a visual mockup or simulated calculator..
